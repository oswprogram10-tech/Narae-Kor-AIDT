# 국어나래 AI (Narae-Kor AIDT)

2022 개정 초등 국어 교육과정 기반 AI 학습 도구 — **"AI가 대신 써 주지 않는"** 초등 국어 코스웨어.

- 목적: 1인·교사 프로젝트, 연구·대회·공모전용
- 개발 순서: ① 쓰기 코치(생각·붓 나래) → ② 문법·어휘 → ③ 읽기 → ④ 매체 → ⑤ 문학 → ⑥ 듣기·말하기 + 음성·카메라 실험 모듈

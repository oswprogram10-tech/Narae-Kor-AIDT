# 5단계: 상상·울림 나래(문학) 설계

작성: 2026-11-06 (계획·검수 Opus, 구현 Sonnet — `CLAUDE.md` 작업 분담)

## 원칙

1. **작품은 자체 창작**(동화 2편, 시 2편, 이후 늘림). 저작권 문제 없음, 검수자가 한 편씩 읽는다.
2. **문학은 정답이 하나가 아닐 때가 많다.** 그래서 채점은 '글 속 근거로 확인할 수 있는 것'에만 쓴다(인물 사이, 사건 순서, 감정의 방향, 표현의 종류). 느낌·해석은 채점하지 않고 **근거 문장과 함께 기록**해 교사가 본다.
3. 2~4단계와 같은 틀: 찍기 방지, 보기 섞기, 서버 채점, 근거 고르기, 연구 데이터. 읽기 핵심부를 다시 쓴다.
4. **AI 인물 편지 답장은 2차로 미룬다.** 아이에게 AI가 '인물'로 말을 거는 기능이라, 작품 맥락 제한·안전 장치·레드팀 시험을 따로 설계한 뒤 넣는다.

### 새 형식
- **mood-scale**: 인물·장면을 정하고 마음 온도(1 아주 차가움 ~ 5 아주 따뜻함)를 고른다. 정답은 범위(예: 4~5) — 글 속 근거로 방향이 분명한 장면만 쓴다. 마음 낱말 보기(정답 하나) + 근거 문장. 풀고 나면 장면 순서대로 마음 그래프가 그려진다(학생이 고른 값).
- **sequence**: 사건 카드 3~5장을 일어난 순서대로 놓기(누르고 → 자리 누르기). 순서는 하나로 분명한 것만.
- 관계도는 `choice-with-evidence` 결과로 그림을 그린다(새 채점 형식 없음).
- 시는 행 단위를 '문장'으로 다룬다(근거·꼬리표 재사용).

## 2차(예정)
- **인물에게 편지 쓰고 답장 받기**([6국05-06], [4국05-02]): 답장은 AI 대신 **교사가 쓰거나 고른 답장 틀**로 먼저 시작하고, AI 답장은 작품 맥락 제한·쓰기 코치 가드레일·레드팀 통과 뒤에 선택 기능으로.
- **갈래 바꿔 쓰기·창작 틀**([6국05-05]): 경험을 시·짧은 이야기로(쓰기 코치 재사용, 대필 금지 원칙 그대로).
- 인상적인 부분 의견 나누기([6국05-04]): 카드뉴스 갤러리처럼 교사 승인 + 정해 둔 반응.
